# Prompts for scenario pictures

Generate each image with an AI image tool (Gemini, ChatGPT/DALL·E, Midjourney, Ideogram…),
then save it as `app/src/main/assets/scenes/<id>.webp`.

Use the same style line on every prompt so the set looks consistent:

> **Style:** clean modern anime illustration, soft cel shading, warm natural light, gentle pastel
> colours, original characters, detailed but uncluttered background, the person in the upper half
> of the frame looking at the viewer, portrait 3:4, no text, no logos, no watermark.

Use original characters only; don't ask for the style or characters of any existing app, anime or studio.
