# Scenario pictures

Put one picture per scenario here, named after its id in `../scenarios.json`:
`intro`, `visit`, `konbini`, `restaurant`, `station`, `doctor`, `weather`, `phone`.

Formats: `.webp` (preferred), `.png` or `.jpg`. Portrait 3:4, about 900 × 1200 px, under 300 KB.
Scenarios without a picture show the kanji art instead. Prompts for generating them are in
`docs/scene-prompts.md`.
